# Десктопная концепция через Text-to-UI (Figma + AI-агент)

**Дата:** 20.10.2026 · **Инструмент:** Claude Code (Opus 5.5) + Figma MCP (`use_figma`, Plugin API)
**Файл Figma:** «Финансы — десктоп (Text-to-UI)», https://www.figma.com/design/RTApibfXFFmLB8MfV0Z6xz
**Результат:** [figma-desktop-home.png](figma-desktop-home.png) (1440 × 900)

## Зачем

Аудит требований показал: приложение — мобильная колонка 448 px, на десктопе она стоит
посреди пустого экрана с нижней панелью вкладок. Требование «адаптивный дизайн
(десктоп + мобильные)» не выполнено. Прежде чем верстать, нужна концепция десктопа.

В ДЗ 3 концепции рисовались как HTML, который писал агент. Здесь использован дизайн-инструмент:
агент по текстовому брифу строит макет прямо в Figma, из редактируемых слоёв и компонентов.

## Бриф (текст → UI)

> Десктопная версия Главной, 1440 × 900, тёмная тема в палитре приложения
> (фон #000, карточки #1C1C1E, акцент #0A84FF, зелёный #34C759, красный #FF453A).
> Слева сайдбар 240 px: логотип «₽ Финансы», главная кнопка «＋ Добавить операцию»,
> навигация Главная / Бюджет / Капитал / Аналитика / Настройки, внизу аккаунт и «Выйти».
> Справа контент с полями 40 px: заголовок «Главная» и подзаголовок с месяцем, выбор периода.
> Сетка: слева широкая колонка — карточка «Расход за месяц» (градиент, сумма, прогресс,
> три мини-плашки План / Остаток / Доход), под ней две карточки рядом: «Капитал» по классам
> активов с итогом и «Бюджет · топ категорий» с полосами план/факт (перерасход красным).
> Справа колонка 420 px «Последние операции»: поле поиска по операциям и категориям,
> 7 строк операции (иконка, название, счёт · дата, сумма; доход зелёным).
> Повторяющиеся элементы — компоненты (пункт меню, строка операции).

## Как шёл процесс

1. Агент создал файл в Figma и проверил доступные шрифты.
2. Построил экран одним скриптом Plugin API: компоненты «Nav item» и «Operation row»,
   из них экземпляры; раскладка — auto-layout, без абсолютных координат.
3. **Проблема:** на первом скриншоте не было ни одного текста. Диагностика: у всех 82 текстовых
   слоёв ширина 0. Шрифт SF Pro (шрифт приложения) есть в списке, но у сервера Figma нет его
   метрик — это локальный шрифт Mac. **Решение:** заменить на Inter, ближайший к системному.
4. Две рамки остались шириной 0 — их раскладка посчиталась, когда текст был нулевым.
   Принудительный пересчёт (FIXED → FILL) исправил.
5. Финальный скриншот проверен глазами: текст не обрезан, нет наложений.

## Что из концепции пошло в код

| Решение концепции | Реализация |
|---|---|
| Сайдбар вместо нижних вкладок на широком экране | `lg:` — боковая навигация, нижняя панель скрыта |
| Кнопка «Добавить операцию» в сайдбаре | главное действие всегда на виду |
| Сетка: широкая колонка + колонка операций | Главная в две колонки на `lg:` |
| Карточки Капитал и Бюджет рядом | двухколоночные сетки на `md:` |
| Поиск в блоке операций | поиск по комментарию и категории на сервере (`q`) |
